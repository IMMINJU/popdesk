# 디자인 토큰 (시안 검토 뒤)

> 시안을 보고 정한 값이다. 기본 강조색만 확정 전이다(1절 강조색). 모양 원칙은 7절, 정한 일은 8절에 있다.
> 정하면 `web/packages/ui`의 토큰 파일로 옮기고 이 파일은 지운다. `design/spec/screens.md` 1·2절(사용 환경, 화면 규칙)도 그때 함께 옮긴다.
> 대비 값은 WCAG 2.1 상대 휘도 공식으로 직접 계산했다. 글자는 4.5:1 이상, 칸 테두리·포커스 테두리 같은 UI 요소는 3:1 이상(1.4.11)을 기준으로 했다.

## 1. 색

이름은 쓰임으로 짓는다(`text`, `danger`). 색 이름(`blue-600`)은 토큰 파일 안에서만 쓰고 컴포넌트는 쓰임 이름만 쓴다.

### 강조색 (브랜딩으로 바뀌는 무리, D-50)

| 토큰 | 밝게 | 어둡게 | 쓰임 |
|---|---|---|---|
| `accent` | `#047857` | `#34D399` | 주 버튼 바탕, 링크, 고른 탭 |
| `accent-hover` | `#065F46` | `#6EE7B7` | 주 버튼 마우스 올림 |
| `on-accent` | `#FFFFFF` | `#032016` | 주 버튼 글자 |
| `accent-subtle` | `#E3F5EE` | `#0D2E23` | 고른 줄, 고른 메뉴 바탕 |

- 기본 강조색은 확정 전이다. 표의 값은 지금 후보인 에메랄드다. 다른 후보는 청록(`#0F766E`/`#2DD4BF`)과 보라(`#6D28D9`/`#B794F6`)이고, 빨강·파랑 계열은 쓰지 않는다(오류·안내 색과 섞인다, D-50). 후보를 바꾸면 아래 대비 표의 강조색 줄을 다시 잰다.
- `accent`는 테마마다 하나씩이다. 관리자가 `#RRGGBB` 하나를 넣으면 앱이 OKLCH 명도만 옮겨 밝게·어둡게 두 값을 만들고, 두 값이 각 바탕에서 글자 대비 4.5:1을 넘을 때만 받는다(D-50, BRAND-3). `accent-hover`, `on-accent`, `accent-subtle`도 만든 값에서 계산한다. 계산 규칙은 브랜딩 묶음(9번)에서 정하고, 첫 묶음은 위 표의 값을 그대로 쓴다.
- 강조색은 상태·오류를 나타내는 데 쓰지 않는다. 브랜딩으로 빨강·초록이 들어와도 뜻이 섞이지 않게.

## 7. 모양 원칙

- 카드와 테두리 상자를 늘어놓지 않는다. 묶음은 여백과 글자 위계(크기, 굵기, `text-muted`)로 나눈다. 꼭 나눠야 하면 `border` 나눔선 한 줄을 쓴다.
- 입력칸은 `field` 바탕에 아래쪽 `border-strong` 1px 선이다. 네 변 테두리를 두르지 않는다. 포커스는 `focus` 테두리(2px, 바깥 간격 2px)다.
- 왼쪽 색 띠 장식은 쓰지 않는다. 내부 댓글도 띠 없이 칸 전체 바탕과 머리 글자로 가른다(1절 내부 표시).
- 상태는 점과 글자로 보인다. 바탕은 칠하지 않는다. 점은 8px(`radius-full`, 테두리 1.5px)이고 1절 표의 글자색을 쓴다. 끝난 상태(종료됨)와 수락 전 계정은 속 빈 점이다.
- 우선순위는 막대 아이콘 태그다. 낮음은 막대 1개, 보통 2개, 높음 3개이고 `sunken` 바탕에 `text` 글자다. 긴급은 `danger` 바탕에 `on-danger` 글자와 느낌표 아이콘이다. 아이콘 옆에 늘 글자를 둔다.
- select는 브라우저의 화살표를 끄고(`appearance: none`) 직접 그린 화살표를 오른쪽 안쪽 `space-3`에 둔다.
- 스크롤바는 맥처럼 가늘게 둔다. 폭 8px, 홈은 투명, 손잡이는 `radius-full`로 둥글게 하고 색은 `border-strong`의 50% 불투명도, 마우스를 올리면 100%다.
- 버튼과 입력칸의 둥글기는 `radius-sm`(4px)이다.

## 8. 정한 것

1. 강조색은 D-50대로다(전 7절 1번의 가). 관리자는 색 하나를 넣고, 앱이 OKLCH 명도만 옮겨 테마마다 `accent`를 하나씩 만든다. 받을지는 만든 두 값으로 본다. spec BRAND-3을 이것에 맞췄다.
2. 기본 강조색은 시안에서 고르는 중이다. 지금 후보는 에메랄드이고 청록·보라도 후보다. 빨강·파랑 계열은 쓰지 않는다. 표의 값은 에메랄드이고 확정 전이다.
3. 포커스 색은 강조색과 따로 두고 브랜딩으로 바뀌지 않는다(지금 값 유지, D-50).
4. Pretendard는 앱에 묶어 낸다(바깥 CDN을 부르지 않는다, D-41). 웹 번들이 1~2MB 커지는 것은 받아들인다.
5. 밀도는 두 벌이다(포털 44px, 콘솔 36px). 앱이 CSS 변수로 한 번에 바꾼다.
6. 중립색은 시안의 따뜻한 중립으로 바꿨다. 입력칸 바탕 `field`를 새로 더했다.
7. 내부 표시는 왼쪽 띠 대신 칸 전체 바탕과 머리 글자다. `internal-text`, `on-internal`을 더했다.
8. 모양 원칙은 7절에 적었다.
