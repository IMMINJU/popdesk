> 콘솔 화면 셋(C-3 문의 목록, C-4 문의 상세, C-9 고객사 상세)과 공용 컴포넌트 둘. 포털은 바뀌지 않는다.
> 문구는 지금 나간 말에 맞췄다(0절). 색과 모양은 `tokens.md`와 있는 컴포넌트를 따른다. 왼쪽 띠, shadcn 꼴은 쓰지 않는다.
> 상태: **메인이 정함, 사용자 확인 전**(2026-10-14).

## 0. 잠긴 테스트와 나간 문구 (초안을 쓰기 전에 읽음)

- `C3IssueList.test.tsx` 79~80줄: 열 머리에 "라벨", "마감일", "SLA"가 없다고 단언한다. 이 묶음의 웹 테스트 탭이 "라벨"과 "마감일"을 빼고 "SLA"는 둔다.
- C-4 머리의 `dl` 칸 이름: 상태, 우선순위, 담당자, 고객사, 올린 사람, 받은 경로, 올린 시각 [소스: `C4IssueDetail.tsx:586-669`]. 이 밖에 있을 때만 보이는 칸(대리 등록, 첫 응답, 해결·종료 시각, 공개 범위)이 더 있다(C-4 웹 탭 보고). 담당자 칸 옆에 "바꾸기" 단추가 있다(610줄). 라벨과 마감일도 같은 꼴로 둔다.
- 이력의 문장 꼴: "{누가} 우선순위를 {전}에서 {뒤}로 바꿨습니다", "{누가} 담당자를 비웠습니다", "{누가} 첨부를 붙임: {이름}" [소스: `IssueHistory.tsx:44-83`].
- C-9의 구역 제목: "소속 고객", "배정 상담원", 빈 상태 "배정된 상담원이 없습니다. …" [소스: `C9CompanyDetail.tsx:936-1011`]. 보관한 고객사에서는 더하는 단추가 없다(`!archived`).
- "작업"이라는 말은 이미 권한 오류("이 작업을 할 권한이 없습니다.")와 정리 작업 화면에 나갔다. 6b의 작업(TASK)과 겹치므로 이 묶음의 문구에는 "작업"을 쓰지 않는다.
- "라벨", "마감", "지남"은 나간 문구에 없다.

## 1. C-4 문의 상세

머리의 `dl`에 두 칸을 더한다. 자리는 "담당자" 다음이다.

| 칸 | 값 | 단추 |
|---|---|---|
| 라벨 | 라벨 칩들(이름순). 없으면 "없음"(회색 글자) | "바꾸기" → 라벨 고르기 |
| 마감일 | `2026년 10월 20일`. 지났으면 날짜 뒤에 "지남" 글자표(경고 색 + 글자). 없으면 "없음" | "바꾸기" → 마감일 고르기 |

- `CLOSED` 문의에는 두 "바꾸기"가 없다(담당자 "바꾸기"는 남는다. permissions.md).
- **라벨 고르기**: 단추 아래에 펼치는 목록(팝오버). 그 고객사의 라벨을 체크 목록으로 보이고 이름으로 거르는 입력이 위에 있다(라벨이 8개를 넘을 때만). 체크하면 바로 붙이고, 풀면 바로 뗀다(한 번에 하나씩 요청, 요청 중인 줄은 막는다). 실패하면 그 줄을 되돌리고 목록 아래에 오류 줄을 보인다.
  - 고객사에 라벨이 없으면: "이 고객사에 라벨이 없습니다." 관리자에게는 "고객사 설정에서 만들기"(C-9의 라벨 구역으로 가는 링크)를 더한다.
  - 20개가 붙어 있으면 체크하지 않은 줄을 막고 "라벨은 20개까지 붙입니다."를 보인다.
- **마감일 고르기**: 날짜 입력 하나와 "정하기", 마감일이 있으면 "지우기". 브라우저 날짜의 오늘보다 이전은 고르지 못하게 하지만(힌트), 판정은 서버가 한다. 서버의 400은 입력 아래에 "오늘이나 그 뒤의 날짜를 고르세요."로 보인다.
- 두 고르기 모두 Esc와 바깥 누르기로 닫히고, 닫히면 "바꾸기" 단추로 초점이 돌아간다. 닫힌 뒤 온 답은 버린다(S6A-AC-86).

## 2. C-3 문의 목록

| 바뀌는 곳 | 어떻게 |
|---|---|
| 열 | "담당자" 다음에 "라벨", "마감일"을 더한다. 라벨은 칩 셋까지 보이고 넘으면 "+2"(가린 이름은 `title`과 화면 읽기 글자로). 마감일은 `10월 20일`(올해가 아니면 연도까지), 지났으면 "지남" |
| 필터 | "고객사"를 하나 고르면 그 옆에 "라벨" 고르기가 생긴다(여럿 고름, `label` 여러 번). 고객사를 바꾸거나 지우면 라벨 필터도 지운다 |
| 정렬 | 필터 줄 끝에 "정렬" 고르기: "올린 시각순"(기본), "마감일순" |
| 주소 | `label`, `sort`를 주소에 남긴다(`issueFilters.ts`) |

- 콘솔 C-3에는 좁은 폭의 카드 꼴이 없다(`DataTable`만 쓴다 [소스: `C3IssueList.tsx:61-86`]). 이 묶음에서도 만들지 않는다. 360 폭에서는 표가 안에서 옆으로 스크롤하고, 페이지가 넘치지 않는 것만 단언한다(C-4 웹 탭 보고로 고침).
- 라벨 필터를 걸었는데 문의가 없으면 지금의 "이 쪽에는 문의가 없습니다"를 그대로 쓴다.

## 3. 이력의 문장

| `field` | 문장 |
|---|---|
| `LABEL` | 붙임: "{누가} 라벨을 붙임: {이름}", 뗌: "{누가} 라벨을 뗌: {이름}" |
| `DUE_DATE` | 정함: "{누가} 마감일을 {날짜}로 정했습니다", 바꿈: "{누가} 마감일을 {전}에서 {뒤}로 바꿨습니다", 지움: "{누가} 마감일을 지웠습니다" |

첨부의 "붙임:" 꼴에 맞췄다. 라벨 이름은 이력에 적힌 그때의 이름이다(지금 라벨의 색은 쓰지 않는다. 글자만).

## 4. C-9 고객사 상세 (관리자)

"배정 상담원" 다음에 "라벨" 구역을 둔다. 상담원에게는 구역이 없다(상담원은 C-9를 보지 못한다. `<AdminOnly>`).

| 상태 | 보이는 것 |
|---|---|
| 목록 | 줄마다 라벨 칩(이름과 색), "문의 {n}건", "고치기", "지우기". 이름순 |
| 빈 상태 | "아직 라벨이 없습니다." 보관하지 않은 고객사면 "라벨 만들기" 단추 |
| 만들기·고치기 | 대화상자: 이름(1~30자, 글자 수 표시), 색(견본 여덟 + `#RRGGBB` 입력, 기본 회색 `#808080`), 미리 보기 칩. 409는 이름 칸 아래 "이 고객사에 같은 이름의 라벨이 있습니다." |
| 지우기 | 확인 대화상자: "라벨 '{이름}'을 지웁니다. 붙어 있는 문의 {n}건에서도 떨어집니다. 이력에는 남지 않습니다." 단추 "지우기"(위험 색) |
| 200개 | "라벨 만들기"를 막고 "라벨은 고객사마다 200개까지 만듭니다." |
| 보관한 고객사 | "라벨 만들기"가 없다. 고치기와 지우기는 있다 |

색 견본 여덟은 `tokens.md`의 알림 색과 강조색 후보에서 골랐다(C-4 웹 탭, 대비는 WCAG 2.1로 계산): 회색 `#808080`, 빨강 `#C0262D`, 주황 `#B07A00`, 노랑 `#F2C14E`, 초록 `#1F7A3A`, 청록 `#0F766E`, 파랑 `#245FB0`, 보라 `#6D28D9`. 모두 검정이나 흰 글자 가운데 큰 쪽이 4.5:1을 넘는다. 강조색 에메랄드는 브랜드 색과 섞여 뺐다. 견본은 라디오 그룹이고 이름(예: "초록")을 화면 읽기 글자로 단다.

## 5. 공용 컴포넌트 (`@popdesk/ui`)

| 컴포넌트 | props(초안, 계약 단계에서 정함) | story |
|---|---|---|
| `LabelChip` | `name`, `color` | 밝은 색·어두운 색·회색, 30자 이름, 밝게·어둡게 |
| `LabelPicker` | `labels`, `selected`, `onToggle(id, on)`, `busyIds`, `limit`, `emptyAction?`, `open`, `onOpenChange` | 빈 목록, 9개 이상(거르기 입력), 20개 찬 것, 요청 중, 오류 |
| `LabelChips` | `labels`, `max`(기본 3), `moreText(hidden)` | 0·2·3·6개, 긴 이름 여럿 |
| `DueDatePicker` | `value`, `min`, `onSubmit`, `onClear`, `busy`, `error`, `open`, `onOpenChange` | 값 없음, 값 있음, 요청 중, 오류 |

문구: 거르기 입력 "라벨 거르기", 거른 결과 없음 "맞는 라벨이 없습니다.", 붙이기·떼기 실패 "라벨을 바꾸지 못했습니다. 다시 해 보세요.", "+n"의 화면 읽기 글자 "라벨 {n}개 더: {이름, 이름}".

`IssueList`는 두 앱 모두 쓰지 않아 바꾸지 않는다. C-3의 라벨 칸과 C-4의 라벨 칸이 `LabelChips`를 같이 쓴다.

글자색은 `labelTextColor(color)`(WCAG 상대 밝기로 검정·흰색 가운데 대비가 큰 쪽)가 정한다. 칩의 테두리는 바탕이 어두운 테마와 비슷할 때를 위해 1px 경계선 토큰을 쓴다.
