# 1a 묶음 화면 상태

> 1a 묶음(사람과 고객사)에서 새로 생기거나 바뀌는 화면의 상태 목록이다. 화면 ID와 화면 규칙(UX-1~11)은 `design/spec/screens.md`의 것이다. 이 파일은 story로 옮기고 지운다(D-27).
> 모든 화면에 걸리는 상태(뼈대, 401, 403, 404, 429, 400의 칸 오류, 저장 중, 떠나기)와 접근성 공통은 첫 묶음에서 정한 것을 그대로 쓴다(`design/spec/screens.md` 6절). 여기에는 그것과 다른 것만 적는다.
> 새 공용 컴포넌트가 필요한지는 설계(C-2)에서 정한다. 지금 보이는 후보는 사진 올리기(자르기 없음)와 상태 배지의 새 값이다.
> 상태: 사용자가 확인했다(2026-10-11). 문구는 한국어 기준이고 영어는 구현 때 맞춘다.

## 1. 새 화면

### P-9·C-16 비밀번호 찾기

로그인 화면의 "비밀번호를 잊었나요?" 링크로 온다. 로그인하지 않은 채로 본다.

| 상태 | 보이는 것 |
|---|---|
| 처음 | 이메일 칸 하나와 "재설정 메일 받기" 버튼. 로그인으로 돌아가는 링크 |
| 보낸 뒤(202) | 칸을 지우고 안내로 바꾼다: "그 주소의 계정이 있으면 메일을 보냈습니다. 1시간 안에 메일의 링크를 여세요." 계정이 있든 없든 같다(S1A-AC-59). 로그인으로 가는 링크 |
| 이메일 꼴이 아님 | 칸 아래 오류. 보내지 않는다 |
| 429 | 공통 상태대로 초를 센다 |

### P-10·C-17 비밀번호 재설정

메일의 링크(`#` 뒤에 토큰)로 온다. 화면이 뜨면 주소창에서 토큰을 지운다(초대 수락과 같다).

| 상태 | 보이는 것 |
|---|---|
| 처음 | 새 비밀번호 칸, 한 번 더 칸, 규칙 안내(10~72자), "비밀번호 바꾸기" 버튼 |
| 두 칸이 다름 | 둘째 칸 아래 오류. 보내지 않는다 |
| 400 `INVALID_INPUT` | 칸 아래에 규칙 오류(너무 짧음, 이메일과 같음 등). 토큰은 살아 있어 다시 낼 수 있다(S1A-AC-11) |
| 400 링크 무효 | 화면 전체를 안내로 바꾼다: "링크가 만료됐거나 이미 썼습니다." "다시 요청하기" 버튼은 비밀번호 찾기로 간다. 없는·만료된·쓴 링크를 구별하지 않는다 |
| 성공 | 로그인 화면으로 가고 토스트: "비밀번호를 바꿨습니다. 새 비밀번호로 로그인하세요." 바로 로그인시키지 않는다 |
| 토큰 없이 옴 | 링크 무효와 같은 안내 |

### P-6·C-6 내 정보

화면 머리의 사용자 이름을 누르면 온다. 세 구역이다.

| 구역 | 상태 | 보이는 것 |
|---|---|---|
| 프로필 | 처음 | 사진(없으면 머리글자), 이름 칸, 이메일(읽기만), 언어 고르기, "저장" 버튼. 포털은 소속 고객사 목록, 콘솔의 상담원은 배정된 고객사 목록을 읽기만으로 보인다 |
| | 저장 성공 | 토스트. 화면 머리의 이름이 바로 바뀐다. 언어를 바꾸면 화면 문구도 바로 바뀐다 |
| 사진 | 사진 없음 | 머리글자와 "사진 올리기" 버튼. 받는 형식과 크기 안내(PNG·JPEG·WebP, 2MB까지) |
| | 사진 있음 | 사진, "바꾸기", "지우기". 지우기는 한 번 더 묻지 않는다(다시 올릴 수 있다) |
| | 올리는 중 | 버튼을 막고 회전 표시 |
| | 413, 400 `UNSUPPORTED_IMAGE`, 400 `IMAGE_TOO_LARGE` | 사진 구역의 오류 띠에 까닭별 문구. 앞 사진은 그대로 둔다 |
| 비밀번호 | 처음 | 지금 비밀번호, 새 비밀번호, 한 번 더, "비밀번호 바꾸기" 버튼 |
| | 400 `CURRENT_PASSWORD_WRONG` | 지금 비밀번호 칸 아래 오류. 다른 칸은 지우지 않는다 |
| | 성공 | 세 칸을 비우고 토스트: "비밀번호를 바꿨습니다. 다른 기기에서는 다시 로그인해야 합니다." 이 화면의 세션은 이어진다 |
| | 429 | 공통 상태대로(다섯 번 틀린 뒤의 15분 막힘도 같은 띠로 보인다) |

## 2. 바뀌는 화면

### P-1·C-1 로그인

- "비밀번호를 잊었나요?" 링크를 더한다.
- 비밀번호를 바꾸거나 재설정한 뒤 온 경우 위의 토스트를 보인다.

### C-10 구성원 목록

| 바뀌는 곳 | 상태 | 보이는 것 |
|---|---|---|
| 목록 위 | 필터 | 역할, 상태 고르기와 이름·이메일 검색 칸. 검색은 입력을 멈추고 300ms 뒤에 보낸다. 결과가 없으면 "조건에 맞는 구성원이 없습니다"와 조건 지우기 |
| 줄 | 사진 | 이름 앞에 사진이나 머리글자 |
| | 상태 배지 | `ACTIVE`, 수락 전, 초대 취소됨, 정지. 색만으로 가르지 않고 글자를 쓴다 |
| 줄 메뉴 | `ACTIVE` | 이름 고치기, 역할 바꾸기(상담 쪽만), 비밀번호 초기화, 정지 |
| | 정지 | 이름 고치기, 정지 풀기 |
| | 수락 전 | 이름 고치기, 초대 다시 보내기, 초대 취소, (SMTP가 없으면) 초대 링크 복사 |
| | 초대 취소됨 | 이름 고치기, 초대 다시 보내기 |
| | 나 자신 | 역할 바꾸기와 정지는 없다(숨긴다) |
| 정지 | 확인 대화상자 | "○○ 님을 정지합니다. 로그인이 끊기고 다시 로그인할 수 없습니다." 확인하면 줄의 배지가 바뀐다 |
| 역할 바꾸기 | 확인 대화상자 | 바뀔 역할과 "○○ 님은 다시 로그인해야 합니다." |
| 비밀번호 초기화 | 확인 대화상자 | "지금 비밀번호를 못 쓰게 하고 재설정 메일을 보냅니다." |
| | 성공(SMTP 있음) | 토스트: "재설정 메일을 보냈습니다." |
| | 성공(SMTP 없음) | 초대 링크 복사와 같은 대화상자에 재설정 링크를 한 번 보인다. 닫으면 다시 볼 수 없다고 적는다 |
| 초대 취소 | 확인 대화상자 | "보낸 초대 링크를 못 쓰게 합니다." |
| 대화상자 공통 | 닫힌 뒤 온 답 | 버린다. 다음에 다른 사람으로 열었을 때 앞사람의 링크나 결과가 보이지 않는다(S1A-AC-58) |

### C-8 고객사 목록

- 줄마다 상태 배지(사용 중, 중지, 보관)를 보인다. 보관된 고객사는 기본으로 숨기고 "보관된 고객사 보기"를 켜면 나온다.

### C-9 고객사 상세

| 바뀌는 곳 | 상태 | 보이는 것 |
|---|---|---|
| 정보 | 고치기 | 이름과 회사명 칸. 코드는 읽기만이고 "코드는 바꿀 수 없습니다" 안내 |
| 상태 | `ACTIVE` | "중지", "보관" 버튼 |
| | `SUSPENDED` | 화면 위에 띠: "중지된 고객사입니다. 새 문의를 받지 않습니다." "다시 사용", "보관" 버튼 |
| | `ARCHIVED` | 화면 위에 띠: "보관된 고객사입니다. 되돌릴 수 없습니다." 고치기, 소속·배정 더하기 버튼은 없다. 빼기는 남는다 |
| | 보관 확인 | 대화상자: "보관하면 되돌릴 수 없습니다. 새 문의, 소속·배정 더하기, 이름 고치기가 막힙니다." 고객사 코드를 입력해야 확인 버튼이 눌린다 |
| 소속 고객 | 더하기 | 고객 계정을 이름·이메일로 찾아 고른다. 이미 소속인 사람은 결과에 "소속됨"으로 나오고 고를 수 없다 |
| | 빼기 | 확인 대화상자: "○○ 님은 이 고객사의 문의를 더 보지 못합니다. 자기가 올린 문의는 계속 봅니다." |
| 배정 상담원 | 빼기 | 확인 대화상자: "○○ 님은 이 고객사의 문의를 더 보지 못합니다." 담당 수는 보이지 않는다(3번 묶음) |
| 400 (보관된 고객사) | 오류 띠 | 다른 탭에서 보관된 뒤 더하기나 고치기를 누른 경우. 화면을 다시 불러온다 |

### P-4 문의 등록

- 고객사 고르기에 중지·보관된 고객사는 고를 수 없게 보이고 까닭을 적는다("새 문의를 받지 않습니다"). 소속 고객사가 모두 그러면 등록 버튼 대신 그 안내를 보인다.
- 400 `COMPANY_NOT_ACTIVE`(쓰는 사이 중지된 경우): 오류 띠를 보이고 입력은 지우지 않는다.
- 파일을 21개째 고르면 더하지 않고 "한 번에 20개까지 붙일 수 있습니다"를 보인다. 서버의 413도 같은 문구다.

### P-5·C-4 문의 상세

- 댓글과 첨부 줄의 사람 표시에 사진을 쓴다. 포털에서 상담 쪽 사람은 사진 없이 "지원팀"이다.
- 포털: 소속에서 빠진 고객이 자기 문의를 열면 댓글 칸과 첨부 올리기·지우기를 숨기고 안내를 보인다("이 고객사 소속이 아니어서 읽기만 할 수 있습니다").

### 모든 화면

- 403 `CSRF_TOKEN_INVALID`: 토큰을 새로 받아 한 번 다시 보낸다. 또 실패하면 오류 띠: "화면이 오래됐습니다. 새로고침한 뒤 다시 하세요." 입력은 지우지 않는다(S1A-AC-57).
- 화면 머리: 사용자 이름 앞에 사진이나 머리글자. 누르면 내 정보로 간다.
