# 7b 묶음 화면 상태

> 콘솔만 바뀐다. 문구는 이미 나간 말을 먼저 쓴다(`ko.ts`). 새 문구는 이 문서의 글자 그대로다.
> 상태: **메인이 정함, 사용자 확인 전**(2026-10-15).

## 0. 잠긴 테스트와 나간 문구

- 옆 메뉴를 그대로 견주는 테스트(6b에서 고침, 7a에서 "휴지통"을 넣음). "통계"는 "내 작업" 다음이다. 상담원 `['문의', '내 작업', '통계']`, 관리자 `['문의', '내 작업', '통계', '고객사', '구성원', '휴지통', '감사 로그', '시스템 상태']`.
- 상태 낱말은 상담 쪽 낱말(`ISSUE_STATUS_WORDS[…].agent`)을 쓴다. 열은 "열림"(접수와 확인을 합친 것)만 새 낱말이다.

## 1. C-5 통계 (새)

경로 `/stats`. 제목 "통계".

| 곳 | 어떻게 |
|---|---|
| 표 | `DataTable`: 고객사(코드와 이름, 보관한 곳은 "보관" 배지), 전체, 열림, 처리 중, 해결, 종료. 숫자는 오른쪽 맞춤. 캡션 "고객사별 문의 수, {n}곳" |
| 링크 | 고객사 이름 → `/issues?companyCode={코드}`. 0이 아닌 수 → 그 고객사와 상태로 거른 `/issues`(`issuesHref`, 열림은 `status`가 둘). 0은 링크가 없다 |
| 안내 | 표 아래 한 줄: "휴지통의 문의는 세지 않습니다." |
| 비었을 때 | 관리자 "아직 고객사가 없습니다." / 상담원 "배정된 고객사가 없습니다." |
| 실패 | `role="alert"` "통계를 읽지 못했습니다. 다시 해 보세요." 와 "다시 읽기" |
| 좁은 폭 | 360에서 표는 안에서 옆으로 스크롤한다 |
