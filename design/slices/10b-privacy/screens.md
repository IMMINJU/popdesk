# 10b 묶음 화면 상태

> 콘솔만 바뀐다: C-9 고객사 상세의 내보내기 구역과 대화상자, C-7 알림함 문장 셋, C-11 휴지통의 "자동 정리". 포털은 바뀌지 않는다. 기준 ID는 `acceptance.md`의 것이다.

## C-9 내보내기 구역

자리: 고객사 상세의 맨 아래 구역(라벨 구역 뒤). "내보내기" 단추는 구역 머리에 하나. 보관한 고객사에도 보인다. 관리자만 보는 화면이라 상담원 갈래는 없다.

| 상태 | 보이는 것 |
|---|---|
| 읽는 중 | 구역 제목 "내보내기"와 자리 표시 |
| 작업 없음 | "아직 내보낸 적이 없습니다." |
| 목록 | 줄마다 상태 배지(진행 중, 완료, 실패, 기간 지남), 요청한 사람, 요청 시각, 크기(완료만), 끝 칸에 "내려받기"(완료만) 또는 실패 까닭 문장 |
| 진행 중 줄이 있음 | 5초마다 다시 읽음(탭이 가려지면 쉼). "내보내기" 단추는 눌리지만 409면 대화상자에 문장. 끝나거나 실패하면 숨긴 상태 줄이 "내보내기가 끝났습니다"·"내보내기가 실패했습니다"를 한 번 읽힘 |
| 다시 읽기 실패 | 목록은 그대로 두고 구역 아래에 "목록을 새로 고치지 못했습니다." 다음 회차에 다시 읽음 |
| 읽기 실패 | 구역 안에 "내보내기 목록을 불러오지 못했습니다." 와 "다시 시도" |

실패 까닭 문장: `INTERRUPTED` "앱이 다시 시작되어 멈췄습니다.", `STORAGE` "첨부 저장소를 읽지 못했습니다.", `DISK` "내보내기 파일을 쓸 공간이 없습니다.", `UNEXPECTED` "알 수 없는 오류로 멈췄습니다."

내려받기는 10a의 확인 도움(`HEAD` 뒤 내려받기)을 쓴다. 404는 "파일이 없습니다. 기간이 지났거나 지워졌습니다."를 구역 안에 보인다. 크기는 `formatBytes`. 배지는 `Badge`.

## 내보내기 대화상자

`Dialog`와 폼. 제목 "{고객사 이름} 내보내기".

1. "이 고객사의 공개 문의, 공개 댓글, 첨부 파일, 소속 고객(이메일과 이름)을 ZIP 파일 하나로 만듭니다. 다 되면 알림함으로 알립니다."
2. 선택 상자 "비공개 문의도 넣기"(기본 끔), 설명 "비공개 문의는 같은 고객사의 다른 고객도 보지 못하는 문의입니다."
3. 선택 상자 "내부 댓글과 작업도 넣기"(기본 끔), 설명 "상담 쪽 사람의 이름은 '지원팀'으로 적습니다. 내부 댓글 본문에 쓴 이름은 그대로 들어갑니다."
4. 단추 "내보내기", "취소".

| 상태 | 보이는 것 |
|---|---|
| 보내는 중 | 단추 "요청하는 중…" |
| 202 | 닫고 목록 맨 위에 진행 중 줄 |
| 409 | 대화상자 안에 "다른 내보내기가 진행 중입니다. 끝난 뒤 다시 시도해 주세요." |
| 503 | 대화상자 안에 "앱이 시작하는 중입니다. 잠시 뒤 다시 시도해 주세요." |
| 404 | 대화상자 안에 "고객사를 찾을 수 없습니다." |
| 연결 실패·그 밖 | 대화상자 안에 지금 화면들의 공통 오류 문장 |
| 닫은 뒤 온 답 | 목록만 다시 읽음 |

## C-7 알림 문장

| 종류 | 문장 | 누르면 |
|---|---|---|
| `COMPANY_EXPORT_READY` | "고객사 {코드} 내보내기가 끝났습니다" | 그 고객사 상세 |
| `COMPANY_EXPORT_FAILED` | "고객사 {코드} 내보내기가 실패했습니다" | 그 고객사 상세 |
| `ISSUE_RETENTION_ARMED` | "문의 자동 정리가 켜졌습니다. 내일부터 종료된 지 {일수}일이 지난 문의 {N}건을 휴지통으로 옮깁니다" | 휴지통(오늘은 비어 있을 수 있다) |

## C-12 감사 로그

`COMPANY_EXPORTED`("고객사 내보내기"), `COMPANY_EXPORT_DOWNLOADED`("고객사 내보내기 받기")는 "고객사" 묶음(10a의 잠긴 테스트가 "내보내기" 묶음을 둘로 못박음, `design.md` 2절). 바뀐 값 이름: `includeInternal` "내부 넣기", `includePrivate` "비공개 넣기", `exportId` "작업".

## C-11 휴지통

지운 사람 칸이 `null`이면 "자동 정리"(회색 글자).
