# 7b 묶음 사전 부검

> 상태: **메인이 정함, 사용자 확인 전**(2026-10-15).

## 1. 상담원이 남의 고객사 수를 봤다

- 통계가 모든 고객사를 늘어놓아 A사만 맡은 상담원이 B사의 문의 수와 이름을 봤다.

막는 것: 고객사를 배정으로 거른다(S7B-AC-03). C-7 틀린 구현으로 본다.

## 2. 수가 목록과 달랐다

- 통계는 휴지통의 문의를 세고 목록은 세지 않았다. 보관한 고객사는 통계에서 빠졌다.

막는 것: 휴지통 조건(S7B-AC-02), 보관한 고객사도 나옴(5절 5). 화면에 "휴지통의 문의는 세지 않습니다."를 적는다.

## 3. 경보가 늘 울리거나 울리지 않았다

- 하루마다 도는 작업이 한 번 실패하자 곧바로 "멈춤"이 됐다.
- 작업이 모두 멈췄는데, 경보를 보는 일도 같은 스레드에서 돌아 함께 멈췄다.

막는 것: 주기 + 24시간(5절 3). 경보는 정리 작업과 같은 스레드, 같은 잠금 아래에서 돈다(설계 4절). 그래서 작업이 실패를 이어 가는 경우는 잡지만, 스레드가 멈추거나 인스턴스 잠금을 잃은 경우는 못 잡는다. 받아들이고 지표(OPS-2)와 상태 확인으로 본다.

## 4. 받아들이는 것

- 통계는 요청마다 센다(STATS-3). 고객사 수천 곳이나 문의 수백만 건에서는 느려질 수 있다. 그때 집계 표를 정한다.
