## 4. 정한 것 (메인이 정함, 사용자 확인 전)

| 무엇 | 정한 것 |
|---|---|
| 로그 줄의 채널 글자 | 코드 그대로 `(MAIL)`. 기준 글을 고쳤다 |
| 다른 `STOPPED` 종류 | 지금 코드에 한도 말고 없다. 테스트는 SMTP 거절의 WARN 줄로 "다른 까닭은 WARN 그대로"를 본다 |
| 뜰 때 끊긴 내보내기 알림 | 바꾸기는 웹 서버 앞(`afterPropertiesSet`), 알림은 첫 관리자가 생긴 뒤(`start()`)로 나눈다. 둘 사이에 앱이 죽으면 그 알림 하나가 빠진다. 내보내기 목록에는 `FAILED`로 남으므로 받아들인다 |
| i18n 테스트 파일 | `packages/i18n`의 첫 테스트로 둔다 |

## 5. 릴리스 노트에 넣을 것

0.12.0에 함께 넣는다(11월 CI 뒤).

- 콘솔 계약 `CompanyMember`에 `anonymized`. 익명 계정을 고객사 담당자로 지정하면 400 `ACCOUNT_ANONYMIZED`(해제는 된다).
- C-9 소속 고객 표가 익명 고객을 "익명화됨"으로 보이고 "담당자로 지정"을 두지 않는다.
- 앱이 뜰 때 끊긴 고객사 내보내기도 모든 관리자에게 `COMPANY_EXPORT_FAILED`를 남긴다.
- 자동 정리 켜짐 알림이 대상 0건일 때 "지금은 종료된 지 N일이 지난 문의가 없습니다."라고 쓴다.
- 받는 사람 한도에 걸린 메일의 로그 줄이 WARN에서 INFO로 내려간다. 경보 `DELIVERY_FAILED`의 WARN 한 줄과 지표 `popdesk_mail_rate_limited_total`은 그대로다.
