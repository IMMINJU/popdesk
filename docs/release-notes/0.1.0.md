# popdesk 0.1.0

The first slice, end to end: an empty install, the first admin, inviting a customer, a request with attachments from the customer portal, an agent's answer from the console, the email and webhook that follow, and metrics.

This version is for trying popdesk out. It is not ready for production.

## The image is not published yet

`deploy/compose.yml` points at `ghcr.io/imminju/popdesk:0.1.0`, and no registry has that image. Build it from this tag under the same name, then start Compose:

```
git checkout v0.1.0
docker build -t ghcr.io/imminju/popdesk:0.1.0 .
docker compose -f deploy/compose.yml up -d
```

Only `amd64` was built and tested. Publishing `amd64` and `arm64` images, and the SBOM, comes with a later release.

## What is in it

- First start: migrations, the single-instance lock, and the first admin from `POPDESK_ADMIN_EMAIL` and `POPDESK_ADMIN_PASSWORD`.
- Accounts: sign-in, sessions, lockout, rate limits, customer companies, invitations by email or by copied link.
- Requests: create, list, and read in the portal and the console; public and internal comments; attachments stored in the database.
- The customer-company boundary: a customer sees only their own company's requests, and never internal comments or who the agent is.
- Notifications: a send queue with retries for email (SMTP) and one team webhook.
- Operations: `popdesk backup`, `popdesk restore`, `popdesk admin reset-password`, health and metrics on the management port, a Grafana dashboard, the audit log.

Search, filters, labels, due dates, internal tasks, and OIDC are not in this version.

## Settings to know

The keys are listed in [configuration.md](../operate/configuration.md).

- `POPDESK_DB_PASSWORD` is required. Compose stops with a message when it is missing.
- `POPDESK_LOCALE` accepts only `en` or `ko` (upper case and spaces around it are fine). With any other value the app does not become ready and logs the key name.
- `POPDESK_STORAGE` accepts only `db` in this version.
- `POPDESK_TRUSTED_PROXIES` has a wide default. Narrow it when no proxy is in front of the app (configuration.md, "TLS").
- A container memory limit, if you set one, needs at least 0.75 GB.

## Database

Migrations 1 to 4 create the schema. There is no earlier version to upgrade from.

From the next version on: back up before you upgrade (`popdesk backup <file>`). Migrations only move forward; going back means restoring that backup ([upgrade.md](../operate/upgrade.md)).

## Known problems

These are rare or only add log lines, and are fixed after this version:

- An attachment path with an ID that is not a UUID answers 400 instead of 404.
- A file name that is long in UTF-8 (for example 255 Korean characters; about 150 characters and up) is refused with 413 when attached, although names up to 255 characters are allowed.
- While the database is down or another instance holds the lock, the app logs a warning every second.
- `popdesk restore` checks for an empty database in a way that misses tables its user cannot see.
- If creating a request loses a race with the cleanup job, an unused attachment row can stay behind.
- Database error detail can reach the log when an operator replaces the database URL without `logServerErrorDetail=false`.
