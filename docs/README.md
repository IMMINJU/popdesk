# popdesk documentation

Public documentation. A documentation site will be built from this folder. Pages are added as features land; until then most sections are empty.

| Section | For | Will cover |
|---|---|---|
| [`operate/`](operate/) | People who install and run popdesk | Installation, size limits, [configuration and TLS](operate/configuration.md), [audit log](operate/audit-log.md), [personal data](operate/privacy.md), email, backup, [upgrade](operate/upgrade.md) |
| [`use/`](use/) | Admins, agents, and customers | First admin setup, permission table, agent console, customer portal |
| [`integrate/`](integrate/) | People who connect other systems | [API conventions](integrate/conventions.md), API reference (`openapi-portal.json`, `openapi-console.json`), webhooks |
| [`contribute/`](contribute/) | Contributors | Development setup, tests, release process |

Builders' notes (decisions, roadmap, work in progress) are in [`../design/`](../design/) and are not part of this documentation.
