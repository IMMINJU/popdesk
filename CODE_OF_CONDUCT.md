# Code of Conduct

popdesk adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies in all project spaces (issues, pull requests, discussions, and any chat we run) and when someone represents the project in public.

In short: be respectful, assume good faith, welcome newcomers, and focus on the work. Harassment, personal attacks, and publishing others' private information are not acceptable.

## Reporting

Report unacceptable behavior to the maintainers at **[contact to be set before the repository goes public]**. Reports are handled privately. We will review every report and respond as described in the Contributor Covenant's enforcement guidelines (correction, warning, temporary ban, permanent ban).

Do not use this channel for security vulnerabilities; see [SECURITY.md](SECURITY.md).
