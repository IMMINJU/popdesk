# Code of Conduct

popdesk adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies in all project spaces (issues, pull requests, discussions, and any chat we run) and when someone represents the project in public.

In short: be respectful, assume good faith, welcome newcomers, and focus on the work. Harassment, personal attacks, and publishing others' private information are not acceptable.

## Reporting

Report unacceptable behavior privately to the maintainer, [@IMMINJU](https://github.com/IMMINJU), using the contact listed on their GitHub profile. Do not open a public issue for it. For content posted on GitHub, you can also use GitHub's [Report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) feature, which goes to GitHub staff. Reports are handled privately. We will review every report and respond as described in the Contributor Covenant's enforcement guidelines (correction, warning, temporary ban, permanent ban).

Do not use this channel for security vulnerabilities; see [SECURITY.md](SECURITY.md).
