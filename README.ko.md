# popdesk

지원팀 하나가 여러 고객사의 문의를 받는 설치형 헬프데스크입니다.
고객은 고객 포털에서 문의를 올리고 진행을 보고, 상담원은 상담 콘솔에서 답하고 내부 작업을 기록합니다.

[English](README.md) · 영어판이 정본입니다. 둘이 다르면 영어판을 따릅니다.

> **지금은 0.4.0입니다.** 빈 설치, 첫 관리자, 초대, 첨부가 있는 문의, 상담원 답변, 그에 따른 메일과 웹훅에 더해 구성원과 고객사 관리, 비밀번호 찾기, 해시 사슬로 이어진 감사 로그, 고객사 담당자와 문의의 필터, 검색, 고치기, 담당자, 상태 변경, 종료와 재오픈, 이력, 대리 등록이 있고, 이번에 댓글 고치기와 지우기, 멘션, 두 앱의 알림함, 늘어난 메일, 운영자가 보내기 상태를 보고 다시 보내는 화면이 들어갔습니다. 이미지는 아직 레지스트리에 올리지 않았으니 태그에서 직접 빌드합니다([릴리스 노트](docs/release-notes/0.4.0.md)). 운영에 쓸 수 있는 상태가 아닙니다. 계획과 결정은 [`design/`](design/)에 있습니다.
>
> `main`은 0.4.0보다 앞서 있고, 아직 내지 않은 0.5.0을 만드는 중입니다. 써 보려면 `v0.4.0` 태그를 받으세요.

## 목표

- **컨테이너 둘.** 앱 이미지 하나와 PostgreSQL 하나. `docker compose up`이면 헬프데스크가 뜹니다.
- **작은 PC에서도.** 16GB 노트북에서 개발하고 돌립니다.
- **분명한 경계.** 고객은 다른 고객사의 문의를 볼 수 없습니다. 내부 댓글, 작업, 담당자는 고객에게 보이지 않습니다.
- **남는 기록.** 문의마다 대화, 상태 이력, 내부 작업 기록이 한곳에 남고, 관리 작업은 감사 로그에 남습니다.

`main`에 있고 0.5.0에 들어갈 것: 본문 이미지와 첨부의 S3 저장, 라벨, 마감일, 담당자와 마감일이 있는 내부 작업, 고객사를 넘는 문의 연결(중복·관련), 휴지통과 자동 종료, 고객사별 건수, SLA 기한과 알림, 브랜딩, 개인정보 내보내기와 익명화, OIDC 로그인, 메일로 문의 받기, 영어 화면.

## 하지 않을 것

채팅·전화·메신저 채널, 자가 가입, SLA 통계, 실시간 푸시, 네이티브 앱, 설치 하나에 여러 팀(당분간). [`design/roadmap.md`](design/roadmap.md)를 보세요.
